Screenshots: evidence/finance/*.png.
- Backend path is sound: POST /api/v1/auth/mfa/enroll (201, returns secret + otpauth URI) -> POST enroll {code} (200 enabled) -> POST /api/v1/auth/mfa/verify {code} (200, sets pawspace_admin_mfa cookie) -> /api/payroll, finance-control, gst-accounting, partner-finance, payment-reconciliation all 200.
