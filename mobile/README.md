# PawSpace Mobile

Shared Expo/React Native customer application for iOS and Android.

## Phase 1 included

- Premium PawSpace design system
- Customer home and all service verticals
- Multi-pet switching and pet-care timeline
- Upcoming bookings, rescheduling and tracking entry points
- Subscription wallet preview
- Account, payment, support and privacy navigation

## Run locally

```bash
npm install
npm start
```

Use Expo Go for device testing. Native store builds will be configured after the backend, authentication and production credentials are connected.
